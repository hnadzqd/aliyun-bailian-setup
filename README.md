## 开通前要准备什么

一个阿里云账号就够个人用户用了，但有两个前置事项直接影响开通体验：实名认证和RAM权限。

### 实名认证，决定免费额度用完之后怎么办

这一步别跳过。官方规则是：未认证用户的免费额度用完后无法继续调用，必须先完成认证并充值；已认证用户的额度用完后自动转为按量付费，中间不用停下来操作。认证做不做，决定你额度耗尽那天是接着用，还是停下来补手续。

认证入口在阿里云官网右上角的“账号中心”→“实名认证”，个人认证按提示提供身份证信息即可。

### 用RAM子账号开通？权限必须精确到AliyunBailianFullAccess

百炼允许用RAM账号开通，但条件卡得比较死：该RAM账号必须被授予`AliyunBailianFullAccess`系统策略，官方明确说明其他管控层权限不行，缺了它，开通时会直接提示无权限。

如果你是团队管理员，让同事用子账号去开通之前，先在RAM控制台把这个策略授上。个人用户用主账号操作，没有这一步。

## 地域怎么选：开通、API-Key、调用地址全是分地域的

开通环节最容易被理解错的一点：百炼按地域独立开通。你在北京地域点了同意协议，新加坡地域仍然是未开通状态，要用就得切换过去再同意一次。API-Key同样分地域管理，北京、新加坡、美国各有自己的Key页面，不能混用。

调用地址（base_url）也跟着地域走，而且互不通用。官方文档给出的格式是 `https://{WorkspaceId}.{地域代号}.maas.aliyuncs.com/compatible-mode/v1`，其中{WorkspaceId}替换成你的业务空间ID：

| 华北2（北京） | cn-beijing |
| 新加坡 | ap-southeast-1 |
| 美国（弗吉尼亚） | us-east-1 |
| 德国（法兰克福） | eu-central-1 |

怎么选：国内业务和大多数个人开发者，开北京地域就行，新人免费额度也是北京地域专属；服务海外用户再按用户所在位置选新加坡或美国。地域选错了不会报大错，通常是Key找不到或调用地址对不上，返工一次挺耽误事，开通前想清楚。

## 开通后第一步：创建API Key，跑通第一次调用

开通完成后，第一件事是创建API Key。百炼兼容OpenAI接口规范，已有的OpenAI代码只需要改三处——API Key、base_url和模型名称，就能迁移过来。

创建Key的位置：登录百炼控制台，点页面右上角的头像图标，在下拉菜单里选“API-KEY”（新版界面左侧栏直接有"API-Key"入口），点“创建”生成。Key生成后记得存好，它是调用凭证，后面不用了也可以在同一页面删掉。

模型方面，开箱即用的千问系列分三档：千问Max效果最好，适合复杂的多步骤任务，最新的qwen3.8-max推理能力全面超越前代，官方也推荐优先选用；千问Plus在效果、速度和成本之间比较均衡，是多数场景的推荐选择；千问Flash高性价比、低延迟，简单任务够用。除千问外，DeepSeek、Kimi、GLM等第三方模型也能直接调用。

第一次调用可以用curl验证Key是否可用（{WorkspaceId}换成业务空间ID）：

bash
curl -X POST https://{WorkspaceId}.cn-beijing.maas.aliyuncs.com/compatible-mode/v1/chat/completions \
  -H "Authorization: Bearer $DASHSCOPE_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"model": "qwen3.8-max", "messages": [{"role": "user", "content": "你是谁？"}]}'


想在AI编程工具或命令行里用，百炼也提供CLI，安装后可以一行指令调用全栈模型服务，这里不展开。

## 常见问题

### 开通百炼需要付费吗

不需要。开通免费，调用、微调、部署模型时才按量计费。

### 进入控制台没有弹出服务协议怎么办

说明该地域已经开通过了，直接使用即可。

### RAM子账号开通时提示无权限

让主账号在RAM控制台为该子账号授予`AliyunBailianFullAccess`系统策略。其他管控层权限无效，必须是这一个策略。

### 百炼和千问是什么关系

千问是模型，百炼是提供千问系列等多种大模型的服务平台。开通百炼后就能调用千问全系列以及DeepSeek等第三方模型。

### 我的数据会被拿去训练模型吗

官方说明不会将用户数据用于模型训练，构建应用和训练过程中传输的数据会经过AES-256加密。

### 有手机App吗

没有官方独立手机应用，主要通过Web控制台访问。
